Proyecto de Gestión de Empleados, Sucursales y Ciudades
Este proyecto implementa un sistema de gestión de empleados, sucursales y ciudades en C++. Utiliza estructuras de datos avanzadas como árboles, listas y colas para optimizar la eficiencia y la organización de la información.

Descripción
El objetivo de este proyecto es proporcionar un sistema eficiente para gestionar la información de empleados, sucursales y ciudades. Utilizando árboles, listas y colas, el sistema permite realizar operaciones de búsqueda, inserción y eliminación de manera óptima.

Estructuras de Datos Utilizadas
Árboles: Se utilizan para almacenar y gestionar la información de los empleados, permitiendo búsquedas y actualizaciones rápidas.
Listas: Se utilizan para mantener listas enlazadas de sucursales y ciudades, facilitando la inserción y eliminación de elementos.
Colas: Se utilizan para gestionar las operaciones en cola, como las solicitudes de los empleados, de manera eficiente.
